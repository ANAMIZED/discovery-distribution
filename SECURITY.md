# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting

Do not open public issues for security problems in consumer products built with this playbook.
Report packaging flaws in this repo via private advisory when available.

## Scope

This repository is process and templates, not a runtime.
Treat verify scripts and CI as integrity-critical.
